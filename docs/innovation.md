> 每一点都标明状态：**已实现**（结课版能演示）或**已设计、待验证**（在完整计划里，结课版只做了试点）。

## 0. 汇报用的版本（可以直接放进幻灯片）

1. **研究对象新**：据我们检索，现有的视频辅助翻译数据和评测集中在英日、英中方向。本项目在**中日方向、用真实视频**，专门检验声音和画面能不能补上中日之间的“信息差”：是不是提问、礼貌程度。
2. **评测方法新**：提出“**按文字能否自行恢复来分层**”的现象级评测。把问句按疑问标记分成五类，单独测量只能靠语调判断的那一类，避免模态的作用被容易的样本稀释。这种做法不需要任何新的人工标注。
3. **实验设计更严格**：同一个模型、只换输入，并且显式控制两种以往容易忽略的信息泄漏：语音识别的标点泄漏了语调，音频窗口泄漏了别人的台词。再用错配的声音和画面做反事实对照，确认模型确实在用这些信息。
4. **系统即工具**：视频翻译系统在输出字幕的同时，自动标出声音或画面改变了译文的句子，并按数据集格式导出。同一套系统既是应用原型，也是低人工构建中日多模态数据集的工具。完整的构建方法已经设计好，结课版完成了试点。

时间紧的话讲前三条；第四条作为系统展示时顺带说明。

**注意（交差版）**：如果没有做 WMT26 实验（加分项），第二条和第三条只能作为“方法设计”来讲，没有数字支撑。哪怕只多半天，也建议跑 30 段子集（`docs/build_multimodal_translation.md` §10）。交差版不建数据集，所以第四条里的“导出数据集格式”只是系统功能，不能说已经挖出了数据。

## 2. 创新点一：研究对象——中日方向、真实视频、“信息差”现象（已实现）

- **内容**：中→日翻译时，日语必须写清楚的信息（是不是提问、对谁说话该用什么礼貌程度），中文原文里常常没有，只能从声音和画面里得到。本项目在真实视频上，系统地检验全模态模型能不能用上这些信息。日→中方向作为补充。
- **和已有工作的区别**：上表里的视频翻译数据集和评测，没有一个覆盖中日方向的这类现象。WMT 的中日视频测试集只评整体质量。
- **为什么重要**：中日之间的信息差有语言学根据：中文问句可以只靠语调，日语要用「か」或问号；中文“你”不分对象，日语要在敬体和常体之间选择。所以这正是声音和画面应该起作用的地方。
- **用什么支撑**：WMT26 中→日实验的结果表（`reports/eval_wmt26.md`）。
- **表述注意**：说“据我们检索，中日方向还没有……”，不说“世界首次”。

## 3. 创新点二：评测方法——按“文字能否自行恢复”分层（已实现）

- **内容**：对每一种现象，先把“只看文字就能判断”和“必须靠声音或画面才能判断”的样本分开，再在后者上测模态的作用。以问句为例，按中文原文的疑问标记分成五类：
  - Q1 附加问；
  - Q2 语气词；
  - Q3 正反问；
  - Q4 疑问代词；
  - Q5 没有任何疑问标记，只能靠语调。

  文体方面，报告和“全部译成常体”这一基线的比较，以及 κ。
- **和已有工作的区别**：
  - CoMMuTE、ContraProST 是专门构造对比样本，从设计上保证有歧义，成本是要人工造数据；
  - 在自然测试集（例如 WMT）上，常见做法只算整体分数，需要模态的样本被大量不需要的样本冲淡；
  - 本项目的方法直接从已有的真实视频测试集里分离出“必须靠模态”的子集，不需要新的人工标注，换一个有人工转写的语向也能用。
- **为什么重要**：129 句问句只能检出约 8–13 个百分点以上的差别（`docs/mvp_analysis.md` §2.6）。效果如果集中在 Q5，不分层就很可能看不出来。
- **用什么支撑**：Q1–Q5 各类的数量和各条件的判对率表。如果 Q5 上的差别明显大于总体，就直接证明了分层的必要；如果各类都没有差别，结论是“模型没有利用语调”，同样成立。
- **表述注意**：分类规则是启发式的（例如“几个”不一定是疑问），报告里要写出规则。

## 4. 创新点三：防信息泄漏的受控对照（已实现）

- **内容**：
  - 同一个模型、同一组参数，只换输入：只给文字、语音识别文字、加声音、加画面、全给。
  - 显式控制两种泄漏：
    1. **语音识别标点泄漏语调**：识别模型加的问号，本身就是“听”出来的。不去掉它，“声音有用”就被算到文字头上。所以基线条件把句末问号统一换成句号，另设一个保留标点的条件，专门测量这部分。
    2. **音频窗口泄漏别人的台词**：片段的声音如果和画面一样长，模型会听到对方后面的回答。所以音频只保留目标这一句，其余静音。
  - 反事实对照：把声音或画面换成别的视频的。如果译文照样“变好”，说明提升不是来自证据本身。
  - “全给”条件用模型原生的音画交错方式输入，另设分开输入作对照，检验输入方式本身的影响。
- **和已有工作的区别**：错配对照借鉴了 Elliott（2018）和 Wu 等（2021）。新的部分是：在语音加视频的翻译里，把标点泄漏和音频窗口泄漏这两条通道显式地控制住，并且按声音、画面分别做反事实。
- **为什么重要**：Wu 等（2021）发现，多模态翻译的很多提升其实来自正则化效果，而不是图像内容。没有这些控制，“加了视频变好了”这个结论站不住。
- **用什么支撑**：
  - A 对 B：标点的作用；
  - C 对 C 错配、D 对 D 错配：模型是否真的在用证据；
  - E 对 E 分开输入（可选）：输入方式的影响。
- **表述注意**：不能说“提出了反事实对照方法”，这是借鉴来的；可以说“系统地应用于语音加视频的中日翻译，并控制了两类泄漏”。

## 5. 创新点四：翻译即挖掘的系统（已实现原型）

- **内容**：一套流水线，从视频到语音识别、切句，再到逐句的四条件翻译。页面上标出声音或画面改变了译文的句子，同时按数据集的格式导出这些句子。
- **和已有工作的区别**：现有的视频字幕翻译工具只用识别出的文字翻译，不看画面，也不比较不同输入的效果。本系统让“模态的作用”逐句可见，而且运行系统的同时就在积累数据集的候选样本。
- **为什么重要**：既是能演示的应用（带画面理解的字幕翻译），也是以后低成本扩充数据集的工具。
- **用什么支撑**：网页演示、对比页、`data/pilot/candidates.jsonl`。
- **补充一**：句级实时的“两阶段字幕”，每句先出只看文字的译文，再被多模态译文替换，不同就标出来，把模态的作用实时地展示出来。选择句级而不是同传有语言学理由：日语的否定、疑问、礼貌形式和句尾语调都在句末（`docs/realtime_design.md` §2）。这是工程设计上的改进。
- **补充二**：“先感知后翻译”模式让模型先说出它听到的语调、看到的动作和说话对象，再据此翻译，并在页面上显示出来，使模态的作用可以解释。这是工程上的改进，不是理论创新。
- **补充三：语气保留**：先让模型说出它听到的语气（感知第 4 题），再用目标语言自然的语气手段表达，例如中文的语气词、日语的终助词和敬体常体；可选用本人同意的声音，按同样的语气把译文念出来（`docs/tone_preservation.md`）。这是系统功能的扩展。带语气的语音翻译已有 SeamlessExpressive 等工作，但它不支持日语；本项目做的是把语气接进中日字幕翻译，并用自录语气对展示“只看文字的译文不变、看了声音和画面的译文跟着变”。
- **表述注意**：这是工程原型，没有和商用系统比较翻译质量。

## 6. 创新点五：低人工的数据集构建与可靠性诊断（已设计、待验证）

- **内容**（完整计划，`docs/roadmap/` 和 `docs/spec/03_rules.md`）：
  - **答案必须“看过视频”**：训练用的参考译文由能看能听的模型生成，纯文本翻译只作对照。否则模型学到的是“不用看视频”。
  - **多证据自动验证**：一条样本要算“确实需要视频或音频”，必须同时满足：
    1. 同一模型换输入后译法不同；
    2. 不存在在两种理解下都对的“中性译法”；
    3. 另一家模型先自由描述画面，再判断描述里有没有这条线索；
    4. 换掉媒体后译法改变；
    5. 不同家族的模型评审全票支持。

    对语调疑问句，另设一条不依赖大模型的客观通道：多套语音识别的句末问号，加上测出来的句末音高。
  - **可靠性诊断**：不靠人工也能测出自动标签有多可靠，例如：
    - 换成错配视频后评审团仍然全票的比例；
    - 无歧义样本在换媒体后译文乱变的比例；
    - 核验模型在错配片段上误答“有”的比例。

    再加一次 150 条的小样本抽检，校准这些自动标签。
  - **训练对照**：三个学生模型用完全相同的训练答案，只差训练输入：只给文本、给全部模态、给错配的媒体。用来区分“学会了用线索”和“只是多训了一些 token”。
- **和已有工作的区别**：EVA 靠众包逐条判断“视频是否有用”。本方法用多条互相独立的自动证据代替逐条人工判断，并且量化自动判断的误差。
- **状态**：方法已完整设计（六份规范、配置、提示词）；结课版只做了试点，试点用 WMT 的人工参考代替评审团。**汇报时必须说明是“设计 + 试点”，不能说数据集已经建成。**

## 8. 时间允许时可以加强创新性的几件小事

1. **整理 Q1–Q5 分层标注**：只整理成“文档编号、行号、类别”，不含原文和媒体，作为可复用的评测子集说明。是否公开，要先确认 WMT 数据的使用条件。
2. **报告“原生交错”和“分开输入”的对比**：这是关于“怎样把视频交给全模态模型做翻译”的实证发现，成本只是多跑一个条件。
3. **自录最小对作为受控探针**：同一句话配不同的动作或语调，比较翻译结果。样本很少，只用来演示，但能直观地说明方法。
4. **语气对**（pair06–08）：同一句话换一种语气说，只看文字的两版译文必然相同，看多模态的两版是否跟着语气分开。成本只是多录三对视频。

## 9. 被追问时的回答要点

| 追问 | 回答要点 |
|---|---|
| 这些创新是不是只是组合已有方法？ | 错配对照和对比式评测是借鉴的；新的地方在于中日方向的现象选择、按“文字能否恢复”分层的评测、对两种泄漏的显式控制，以及把翻译系统和数据挖掘合在一起 |
| 分层规则准吗？ | 是启发式规则，报告里写明，并列出每类的数量和例子；规则可以替换，方法不依赖某一套具体的规则 |
| 结果如果是“没帮助”，还有创新吗？ | 有。评测方法和实验设计的创新不依赖结果的方向；“模型听得到语调但不会用”在中日方向上得到验证，本身就是发现 |
| 数据集在哪里？ | 结课版是方法设计加试点；完整的构建计划已经写好，结课后按计划实施 |
