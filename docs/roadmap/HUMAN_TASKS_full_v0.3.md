# HUMAN_TASKS：需要研究者做的事

> **存档说明（2026-11-24）**：这是数据集完整建设计划（v0.3），结课后继续用。现在根目录的 `AGENTS.md`、`GOALS.md` 是结课冲刺版（MVP）。
> 恢复方法见 `docs/roadmap/README.md`。本文件里提到的 `AGENTS.md`、`PHASED_GOALS.md`、`docs/HUMAN_TASKS.md`，指的是本目录下对应的 `*_full_v0.3.md`。

Agent 遇到必须由人决定或提供的事，就在这里加一条，然后继续做不依赖它的部分。做完后由你把状态改成“完成”，并在“结果”里写上决定或文件位置。Agent 不能替你填“结果”，也不能改这里已经填好的内容。

格式：

```text
### H<编号> 标题（阶段）
- 状态：待办 / 进行中 / 完成
- 为什么需要：
- 具体要做什么：
- 做完后放在哪里：
- 结果：
```

### H1 确认研究协议（P0 Gate）
- 状态：待办
- 为什么需要：这些决定会改变流水线和判定规则，必须在写代码前定下来。
- 具体要做什么：逐项回答。括号里是默认值，不改就写“同意默认”。
  1. 主方向是日→中（简体），中→日放到 P7。（默认：是）
  2. 数据的预期用途：仅内部 / 受限研究共享 / 打算公开。（默认：仅内部，P7 再决定）
  3. 是否做一次 150 条的抽检（H5，约 60–90 分钟）。不做的话数据集标为 `unaudited`，论文里不能写“经人工验证”。（默认：做）
  4. 是否启用通道 O，用 ASR 问号加句末音高来判定语调疑问句。（默认：启用，`objective.enabled: true`）
  5. 是否接受这个设定：模型能看到台词前 3 秒到后 1 秒的画面，但只能听到这句台词本身的声音；文字上下文只给前 3 句。（默认：接受）
  6. 是否允许调用外部云端 API。（默认：不用，全部用本地开源模型）
  7. `configs/pipeline.yaml` 里 `budget.*` 的确认门槛是否合适：5000 次模型调用、200 元 API 费用、500 MB 下载。
- 做完后放在哪里：写在本条的“结果”里；需要改默认值的，Agent 会改 `configs/pipeline.yaml` 并记入 `docs/decision_log.md`。
