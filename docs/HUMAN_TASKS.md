### H1 开工前的几个决定（M0 之前，约 10 分钟）
- 状态：待办
- 具体要做什么：逐项回答。不改默认值就写“同意默认”。
  1. **截止日期**：哪天交？还剩几天？Agent 会按 `GOALS.md` §B 选 3 天、5 天或 7 天的安排。
  2. **GPU**：打算租什么卡？（默认：AutoDL 上 1 张 48 GB 或 80 GB 的卡跑 7B；只有 24 GB 就用 7B 量化版或 3B；RTX 5090（32 GB）也能用，但要换 PyTorch 2.7 以上、CUDA 12.8 的镜像，见 `docs/environment.md` §10）
  3. **API**：要不要用云端 API 代替本地 GPU？（默认：不用。要用的话，自录视频需要出镜者同意；WMT 的视频能不能上传，由你决定）
  4. **要不要做加分项**：交差版只做多模态翻译功能。如果还能多出半天，就跑 WMT26 中→日的 30 段子集（需要下载约 1.1 GB 视频），让创新点有数字支撑。（默认：时间允许就做）
  5. **自录最小对**：要不要录（见 H2）？默认：录，演示效果最好。
  6. **实时的输入方式**：模拟直播（必须做）之外，要不要做摄像头直播？要不要用云端实时接口（需要 API key 和费用，画面会上传）？（默认：做摄像头直播，不用云端接口）
  7. **语气做到哪一层**：老师要求的“语气”，是译文文字带语气就够了（文字层），还是还要把译文用原说话人的音色、按同样的语气念出来（语音层，要克隆声音）？（默认：文字层必须做；语音层时间够再做，`configs/mvp.yaml` 的 `tts.enabled` 改成 true）

### H2 自录演示视频：最小对 3–5 对、语气对 3 对（可选，强烈推荐，约 30–40 分钟）
- 状态：待办
- 为什么需要：课堂上最直观的演示是“同一句话，配上不同的动作或语调，译文跟着变”。WMT 的视频不能截图放进幻灯片，自录视频可以。
- 具体要做什么：
  1. 用手机横屏录，每段 5–10 秒，安静的房间，人脸和手都在画面里，每段只说一句话。
  2. 每对录 A、B 两个版本，台词完全相同，只改变动作、语调或语气（pair06–08 是语气对，用来演示语气保留，见 `docs/tone_preservation.md` §4）：

     | 对 | 台词 | A 版 | B 版 | 预期读法 |
     |---|---|---|---|---|
     | pair01 | いいよ。 | 点头、微笑 | 摆手、转身走开 | A：接受（好啊）/ B：谢绝（不用了） |
     | pair02 | 田中さんも出ます | 句末明显上扬 | 平稳下降 | A：疑问（田中也参加吗？）/ B：陈述（田中也参加。） |
     | pair03 | すみません | 撞到人后低头 | 举手叫店员 | A：道歉（对不起）/ B：招呼（劳驾、服务员） |
     | pair04（可选） | 你明天也去 | 句末上扬，对着扮演老师的人 | 句末下降，对着朋友 | A：先生も明日いらっしゃいますか / B：明日も行くよ |
     | pair05（可选） | それ、取って。 | 指着盐 | 指着书 | A：把盐递给我 / B：把那本书递给我 |
     | pair06 | すごいね。 | 真心称赞（笑着、语调上扬） | 讽刺（平板、拖长、翻白眼） | A：真厉害！/ B：你可真行啊。 |
     | pair07 | 本当？ | 惊喜 | 怀疑（皱眉） | A：真的吗？太好了！/ B：真的假的？ |
     | pair08 | もういいよ。 | 温和（没关系了） | 生气（不耐烦） | A：好啦，没事了。/ B：行了行了，别说了！ |

  3. 文件命名 `pair01_A.mp4`、`pair01_B.mp4`……，放进 `data/raw/own/`。
  4. 填写 `data/raw/own/pairs.csv`，列为 `pair_id,variant,direction,sentence,context,expected_reading`。`context` 可以留空。
  5. 出镜的人要同意（可以口头同意并录下来），说明只用于课程研究、不公开。用匿名编号，不写真名。
  6. **要做语音层时**，还要单独征得本人同意用他的声音做音色克隆，说明合成的语音只用于课程演示、标明“AI 合成”、不公开。没有这项同意，就用固定的参考音色，不克隆。不克隆 WMT 视频里的人和公众人物。
- 做完后放在哪里：`data/raw/own/`

### H3 算力和下载（M1、M3 之前）
- 状态：WMT26 媒体下载已确认（2026-11-25）。
- 具体要做什么：
  1. 租 GPU（推荐 AutoDL）：优先 1 张 48 GB 的卡；只能租 24 GB 就用 7B 量化版；不要租 V100、T4 等老卡（`docs/environment.md`）。装环境和下载模型时可以先不开 GPU。把显卡型号、显存、CUDA 版本告诉 Agent，或者直接在 GPU 机器上运行 Agent。
  2. 确认下载 WMT26 媒体（约 1.1 GB）。GPU 机器访问 GitHub 很慢或访问不了时，在自己电脑上下载后上传到机器上。
  3. 模型下载不了时，用 ModelScope 或镜像。
  3a. 租的是 RTX 50 系（例如 RTX 5090）时：先把镜像换成 PyTorch 2.7 以上、CUDA 12.8 的版本。从旧实例克隆来的镜像（例如 PyTorch 2.5.1、CUDA 12.4）在 50 系上用不了 GPU（`docs/environment.md` §10）。
  3b. 摄像头直播时，用 SSH 端口转发在自己电脑上打开页面（`ssh -L 6006:127.0.0.1:6006 <登录地址>`），浏览器才允许使用摄像头和麦克风。
  4. 如果启用 API：把地址、模型名、密钥写进 `.env`（不要发给 Agent，不要提交到 git）。
  5. Agent 每次遇到超过 `configs/mvp.yaml` 里 `budget.*` 门槛的下载或 GPU 运行，会在这里追加一条，写明数量和预计用时，等你确认。
