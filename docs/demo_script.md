# 课堂演示脚本

1. 打开「实时翻译」，从「示例片段」选「Wikitongues 片段 · 中文」，点击「开始翻译」。字幕区显示自动识别的方向。浏览器提示等待播放时，点击「开始播放」。字幕区先显示原文，随后显示译文。发生变化时，打开「翻译详情」查看快速译文。
2. 会话结束后可从同一播放器回放，或展开「会话延迟」查看句末到字幕推送的耗时。字幕区可下载 SRT，延迟区可下载 CSV。
3. 切换「结果回放」，选择中文片段的对比运行。点击任一字幕行跳转到视频中的对应时间。展开「译文对比」可筛选有差异的句子，按条件下载双语 SRT。
4. 在回放列表选「先感知后翻译」的会话。展开「逐句详情」中的「模型观察，未核实」，说明语气及强度来自模型的描述。
5. 展示 `reports/figures/` 里的方法图和实测延迟图。若网页有「对照实验」，可按画面分组查看问句、文体、chrF 和 COMET。请说明页面标注的样本数，并用正式评测报告解释置信区间。

## 摄像头现场演示

通过 SSH 转发打开网页，选择「摄像头」，点击开始并授予浏览器权限。界面显示「正在录制」后说一句并停顿。确认识别出的语向和字幕后点击「结束录制」，播放录像并下载 SRT。

## 离线备份

打开复制到课堂电脑的 `reports/html/index.html`。回放包含实际运行的字幕、媒体、对比和模型观察。同一目录下的 `demo_playback.mp4` 录像可作为播放备份。以 [最终报告](../reports/final_report.md) 的运行编号为准，演示时选定与报告一致的模式。
