## 0. 结论先行

1. **方向是对的，大部分事实引用也是对的。** 文件里提到的论文、模型和链接，我逐条核对过，没有发现编造的文献。问题主要是技术细节写得不清楚、几处前后矛盾，再加上整套流程默认靠人工逐条审核，和你现在“全自动”的要求冲突。
2. **“语音识别 → 纯文本翻译模型”这条路做出来的数据，证明不了视频有用。** 这是你新要求里最关键的问题。如果参考译文 `Y` 只由识别出的日文 `X` 经纯文本模型得到，那么 `P(Y | X, V, A) = P(Y | X)`：视频和音频对答案没有任何信息量。用这种数据微调，模型学到的是“忽略视频”，所有消融实验都会显示 T ≈ T+V，研究假设无法成立。
3. **可以全自动，但要改两处。** 第一，参考译文改由能看视频、能听音频的多模态 teacher 生成。第二，同一个 teacher 在 T、T+V、T+A、T+V+A 四种输入下各翻译一遍，再自动比较、反事实测试、换不同家族的模型来评审，由此自动判断“视频/音频是否真的改变了译法”。人工不再逐条检查，只保留按来源做的授权决定、各阶段 Gate 审批，以及一次 1–1.5 小时的小样本抽检。抽检强烈建议做，但可以不做。
4. **有现成的人工参考测试集，不用自己标。** WMT25 General MT 的日→中 speech 部分带视频和人工参考译文；WMT26 General MT 的中→日 speech 部分带视频、人工转写和人工参考。你在旧项目里已经统计过：前者 59 个文档，后者 114 个文档、662 行。它们可以当作独立的外部测试集，也可以用来校准自动评审，不需要任何人工标注。

## 4. 你的“全自动”方案：问题与修正

### 4.1 为什么不能只做“ASR → 纯文本 MT”

```text
你的方案：视频 ──ASR──▶ 日文 X ──纯文本MT──▶ 中文 Y      ⇒ Y 只依赖 X
训练：     (V, A, X) ──▶ Y                               ⇒ 模型学会“忽略 V、A”
评测：     T ≈ T+V ≈ T+A                                 ⇒ 无法证明视频有用
```

经验上也是这样：Elliott（2018）和 Caglayan 等（2019）发现，原文信息完整时图像几乎没有作用；EVA 指出，多数字幕不需要视频就能译对。所以必须让答案来自“看过视频的翻译过程”，并且**自动找出**那些答案确实依赖视频的样本。

### 4.2 修正后的自动方案

```text
授权来源 ─▶ 抽音轨/VAD ─▶ 双 ASR + 一致性过滤 ─▶ 切句/对齐/说话人 ─▶ 片段 + 前文
   ─▶ OCR 屏幕文字检查 ─▶ 纯文本歧义分析（便宜，全量）
   ─▶ 多模态 teacher：T+V+A 译文（全量，作训练目标）
   ─▶ 对候选样本：同一 teacher 跑 T / T+V / T+A + 反事实（换视频）
   ─▶ 语义差异判定 + 线索核验（另一家族模型）+ 评审团（两家族 × 两种顺序）
   ─▶ 自动分桶 core / general / control / rejected + 模态归因
   ─▶ QE 过滤 ─▶ 去重、按频道/作品切分、冻结测试集 ─▶ 导出 ms-swift JSONL
   ─▶ 外部人工参考测试（WMT25 日→中）+ 一次性抽检（推荐）
```

### 4.3 保留的最少人工

| 人工动作 | 频率 | 估计耗时 | 能否省略 |
|---|---|---|---|
| 决定用哪些视频来源、确认授权和使用范围 | 每个来源一次 | 视来源而定 | ❌ 不能（法律责任不能交给模型） |
| 阶段 Gate 审批（读自动生成的报告） | 每阶段一次 | 10–30 分钟 | ❌ 不能（防止跳阶段） |
| 提供 GPU 或 API、接受模型/数据条款 | 一次 | — | ❌ 不能 |
| 一次性抽检：150 条，网页上选“A 更好 / B 更好 / 都可以 / 都不对 / 看不出” | P4 一次 | 约 60–90 分钟 | ⚠️ 可以不做，但数据集只能标为“未经人工校准的自动银标”，论文里不能声称有人工验证的 benchmark |

### 4.4 自动方案本身的风险

| 风险 | 说明 | 对策（已写进 v0.2） |
|---|---|---|
| Teacher 偏差 | teacher 看错动作，或凭空编出线索 | 线索由另一家族的模型用封闭式问题核验；反事实测试；评审团必须全票 |
| 蒸馏上限 | 学生模型通常超不过 teacher | 研究问题定为“学生是否学会使用非语言线索”，用同目标、同骨干的 S_T vs S_TVA vs S_TVA_shuf 来回答 |
| 循环论证 | 用 teacher 的译文当参考来评测 | core 集主指标用对比式“歧义消解准确率”，不依赖参考译文的措辞；另用 WMT25 人工参考做外部评测；teacher 家族的模型不当最终评审 |
| 产出率低 | 自然对话里真正需要视频的句子可能只有几个百分点 | 先用便宜的文本规则定向挖掘（短句、こそあ指示词、授受动词、省略主语、いい/結構/大丈夫/すみません/どうも），同时保留随机样本来估计真实比例 |
| API 条款 | 部分闭源 API 禁止用输出训练模型 | 默认 teacher 用 Apache-2.0 的开源 Omni 模型；用 API 前先核对条款 |
